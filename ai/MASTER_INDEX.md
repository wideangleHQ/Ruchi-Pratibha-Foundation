# Purpose

This folder contains the complete architectural, product, and engineering knowledge for the Ruchi Prativa Foundation digital platform.

Every AI assistant (Codex, Claude, Antigravity, ChatGPT, Cursor, etc.) MUST read this file first before making any architectural or implementation decisions.

This project is intended to become the Foundation's official digital identity for the next 20–30 years.

The objective is not to build a typical NGO website.

The objective is to build an institutional digital platform that preserves history, showcases impact, manages content, and scales with the Foundation's future growth.

# Project Philosophy

Every decision should optimize for:

- Scalability
- Maintainability
- Performance
- Accessibility
- SEO
- Institutional credibility
- Long-term maintainability
- Reusability
- Clean Architecture

Never optimize for speed of coding at the expense of architecture.

---

# Development Principles

- Server Components by default.
- Client Components only when necessary.
- Feature-first architecture.
- Strong typing everywhere.
- Shared design system.
- Modular APIs.
- Strict separation of concerns.
- Zero duplicate business logic.
- Zero duplicated UI patterns.
- Zero architecture drift.
