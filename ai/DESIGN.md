# Ruchi Prativa Foundation Website
# Design System v1.0

> **Design Philosophy:**  
> "A timeless digital institution that celebrates heritage, recognizes excellence, and inspires social impact."

---

# 1. Brand Personality

The website should **NOT** feel like a typical NGO website.

Instead, it should represent a premium institutional identity that combines:

- Heritage
- Prestige
- Trust
- Culture
- Legacy
- Recognition
- Community
- Transparency

Visitors should feel:

> "This is an institution that has been serving society and honouring excellence for nearly three decades."

---

# 19. Accessibility

- WCAG AA Contrast
- Keyboard Navigation
- Visible Focus States
- Minimum 16px body text
- Semantic Heading Hierarchy
- Reduced Motion Support
- Alt Text for all imagery

---

# 20. Performance Guidelines

- Self-host all fonts
- Use only three font families
- Use font-display: swap
- Use CSS Variables for theming
- Prefer SVG icons
- Optimize images in AVIF/WebP
- Lazy load below-the-fold media
- GPU-accelerated animations only (`transform`, `opacity`)
- Avoid heavy blur and glass effects
- Respect `prefers-reduced-motion`
- Maintain excellent Core Web Vitals

---

# 21. Design Principles

Every interface should communicate:

- Heritage before Modernity
- Story before Statistics
- People before Programs
- Trust before Conversion
- Recognition before Promotion
- Simplicity before Decoration
- Timelessness before Trends

The website should not feel like a campaign website.

It should feel like the permanent digital home of Ruchi Prativa Foundation—a living archive of service, recognition, culture, and impact that can represent the institution for decades to come.
