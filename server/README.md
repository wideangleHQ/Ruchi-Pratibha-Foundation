# Ruchi Prativa Foundation — Server Application

Independent NestJS Backend API Application for the Ruchi Prativa Foundation Digital Platform.

## Development

```bash
# Navigate to server directory
cd server

# Install dependencies
npm install

# Generate Prisma client
npm run prisma:generate

# Start development server
npm run start:dev
```

## Production Build

```bash
npm run build
npm run start:prod
```
